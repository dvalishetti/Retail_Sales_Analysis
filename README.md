# Retail Sales Analysis Dashboard

## Project Overview
This project analyzes retail sales data to generate insights on customer purchasing behavior, product performance, and sales trends. The goal is to help businesses make data-driven decisions on inventory, marketing, and pricing.

## Dataset
- Sample dataset: `data/sample_sales.csv`
- Columns include: OrderID, CustomerID, Product, Category, Sales, Quantity, Discount, Profit, Region, OrderDate

## Tools & Technologies
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL
- Tableau (for dashboard visualization)

## Features
- Data cleaning and preprocessing
- Sales trend analysis by category and region
- Top-selling products and revenue-generating customer segments
- Discounts impact on sales
- Payment method analysis

## Instructions
1. Install dependencies from `requirements.txt`
2. Run `data_cleaning.py` to clean the dataset
3. Use `sales_analysis.ipynb` for data analysis and visualization
4. Optional: Connect cleaned data to Tableau for dashboard creation

## Insights (Example)
- Ages 20–50 are the highest revenue-generating customer segment
- Clothing & Footwear produce maximum sales
- Discounts significantly increase spending
- Credit Card and PayPal are the most preferred payment methods
